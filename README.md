# 🪙 Coin Toss Game (Java Console)

## 📌 Project Description
A simple console-based Coin Toss Game developed using Core Java.
The player predicts whether the coin will land on **Head** or **Tail**, and the system randomly generates the result.

## 🚀 Features
- Player prediction (Head / Tail)
- Random coin toss generation
- Score tracking system
- Interactive console gameplay

## 🛠 Concepts Used
✔ Random Class  
✔ String Comparison  
✔ Loops (game loop)  
✔ Conditional Statements  
✔ Score System  

## 🎮 Game Rules
- Player chooses **Head** or **Tail**
- System performs a random coin toss
- If prediction matches → Player wins
- Score increases for correct guesses

## ▶ How to Run
1. Clone the repository
2. Open in Eclipse / IntelliJ
3. Run the main class
